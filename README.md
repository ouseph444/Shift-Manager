## 🌟 Overview

**OT Roster Hub** is a mobile-first, real-time workforce management platform designed exclusively for hospital operating theatre teams. It helps hospitals, surgical centres, and clinical staff eliminate paper schedules, reduce miscommunication, and streamline shift coordination.

### 🎯 Designed For
* 🏥 **Hospitals & Surgical Centres** (Public & Private)
* 👨‍⚕️ **Surgeons & Anaesthetists**
* 👩‍⚕️ **Theatre & Recovery Nurses**
* 🩺 **Clinical Coordinators & Support Staff**

---

## ⚡ Problem vs. Solution

| Traditional Rostering ❌ | OT Roster Hub ✅ |

## ✨ Core Features

### 📅 My Calendar
* **Personalized Views:** Manage your specific shift rotations seamlessly.
* **Custom Shift Types:** Support for Morning, Evening, On-Call, Training, Leave, and more.
* **Visual Clarity:** Beautifully colour-coded system for quick reading.
* **One-Tap Actions:** Quick add or edit entries with a single tap.

### 👥 Team Roster & Directory
* **Department-Wide Visibility:** View everyone's shifts at a single glance.
* **Quick Staff Lookup:** Access contact details and specific department roles dynamically.

### 💬 Team Chat
* **Real-Time Messaging:** Instant interaction with built-in department-specific channels.
* **Shift Swaps:** Send, review, and approve shift swap requests directly within the chat app.

### 🔒 Privacy, Security & Control
* **Strict Data Isolation:** Users only see data corresponding to their exact *Hospital* and *Department*. No cross-hospital leaks.
* **Full Data Transparency:** An dedicated "My Data" tab lets you see exactly what information is stored.
* **Right to Be Forgotten:** One-click account deletion permanently scrubs shifts, profile data, and chat logs.

---

## 🛠 Technology Stack

* **Frontend:** Vanilla HTML5 + Tailwind CSS (Utility-first styling)
* **Icons:** Font Awesome Iconography
* **Backend & DB:** Firebase Firestore (Real-time document storage)
* **Holidays Integration:** Nager.Date API
* **App Standard:** Progressive Web App (PWA)
* **Hosting:** GitHub Pages
